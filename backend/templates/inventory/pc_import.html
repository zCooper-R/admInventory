    Формат файла

    Файл должен содержать лист с заголовками в первой строке:

    Колонка Обяз. Пример
    name✅ПК-001
    inventory_number✅INV-2024-001
    device_type—PC
    cpu—Intel Core i5
    ram—16
    storage_type—SSD
    storage_size—512
    os—Windows 11 Pro
    status—active
    location—Главный офис
    assigned_to—ivanov

    Обновление по inventory_number: если запись существует — будет обновлена.
